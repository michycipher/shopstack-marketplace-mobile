# Contributing to CartUp Mobile

All changes should be tracked and reviewed before they reach `main`.

## Change workflow

1. Open an issue describing the bug, feature, or maintenance task.
2. Create a focused branch from `main`, for example `codex/12-improve-cart-sync`.
3. Implement the change and add or update tests where practical.
4. Run the checks documented in the README.
5. Open a pull request that references the issue and explains the validation performed.
6. Complete code review and resolve all review feedback before merging.

Direct pushes to `main` are reserved for repository setup and urgent maintenance.
